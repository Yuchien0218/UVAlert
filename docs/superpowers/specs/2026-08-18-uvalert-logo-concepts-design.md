## 二、品牌目標

Logo 要讓人感受到「懂防曬知識、用生活化方式播報的氣象情報員」，並兼具：

- **防曬氣象管家**：有時間、天候與提醒節奏的專業感。
- **防曬生活編輯部**：成熟、溫暖、整齊，像經過編輯的每日生活情報。
- **核心產品辨識**：專案首要任務是協助記得防曬乳補擦，不是醫療診斷、購物商城或一般天氣預報。

主要受眾是容易忙到忘記擦或補擦防曬的台灣女性。視覺語氣應像貼心、可信任的生活情報，不責備、不製造罪惡感，也不走幼稚可愛路線。

## 三、品牌文字與組合形式

- 中文主標固定使用「防曬晴報員」。
- 英文副標固定使用 `UVAlert`，尺寸與視覺權重低於中文主標。
- 每個概念都要包含：
  1. 可獨立使用的圖標。
  2. 圖標＋「防曬晴報員」＋`UVAlert` 的橫式完整 Logo。
- 完整 Logo 用於網站／PWA 頁首、衛教公開頁與分享圖片。
- 獨立圖標用於 App／PWA icon、favicon、通知圖示與小尺寸品牌標記。

第一輪概念板的中文必須正確顯示，不接受生成式圖片常見的錯字。若圖像模型無法穩定產生中文，圖標與文字組合分開製作，再以精確字體排版組合。

## 四、共同視覺規則

### 4.1 第一輪概念配色

- 暖象牙底：`#FAF5EC`
- 陶土杏桃主圖形：`#9F5E42`
- 深咖啡文字／單色圖形：`#2E2925`

UV 風險色不進入 Logo 主配色。所有方案另檢查深咖啡單色版，確保 Logo 不依賴彩色才能辨識。正式品牌色仍需在選定 Logo 後，和完整 UI 設計系統一起確認。

### 4.2 字體方向

- 中文主標：`Noto Serif TC` Medium／500，呈現成熟的生活編輯感。
- 英文副標：`Inter` Medium／500，字距略放寬，保留清楚的氣象資訊感。
- 不使用手寫字、圓體、兒童字體或過度高對比的裝飾明體。

### 4.3 圖形原則

- 使用簡單幾何、均勻線條與充足留白。
- 圖標在 32px 尺寸仍需辨認主要輪廓。
- 圖形不可只靠顏色傳達意義。
- 不把「安全」「有效防護」畫成已完成或保證狀態。

## 五、六款概念

### 1. 晨線

半圓太陽從單一道地平線升起，射線數量控制在零至三條。重點是每天查看晴報的溫暖儀式感，圖形最簡潔、最容易縮小。需避免做成一般日出旅遊品牌。

### 2. 晴窗

太陽圓形結合開放式視窗、編輯版面框或缺角矩形。框線不完全封閉，讓氣象資訊與生活專題兩種角色同時存在。需避免像相機取景框或圖片裁切工具。

### 3. 補擦環

太陽置於不完整的圓形提醒環中，環上保留一個小節點，暗示下一次補擦。不可加入傳統時鐘指針，避免變成計時器或鬧鐘 App。

### 4. 日照節點

以兩段簡潔弧線與兩個節點表達「已擦 → 到時補擦」的節奏。太陽可作其中一個節點或弧線中心。圖形需要比補擦環更柔和、較不像儀表板。

### 5. 晴報框

太陽搭配編輯頁面的角標、底線或短分隔線，像每日生活快報的刊頭。圖標最多保留一個框角和一條資訊線，避免縮小後過於零碎。

### 6. 播報印記

極簡太陽圓點搭配三條長度不同的短資訊線，形成可獨立使用的播報摘要印記。需避免像漢堡選單、文字對齊按鈕或一般新聞 App。

## 六、禁止方向

- 不使用人物、女性側臉、氣象主播角色或吉祥物。
- 不使用卡通笑臉太陽、可愛腮紅或童趣粗圓線條。
- 不使用盾牌、醫療十字、警報鈴、驚嘆號作主要圖形。
- 不使用防曬乳瓶罐作主要識別。
- 不使用綠色暗示安全、防護完成或可放心曝曬。
- 不使用亮黃、飽和紅或多色 UV 漸層作品牌主配色。
- 不沿用舊 Logo、舊截圖或封存視覺資產。
- 不使用「已勾選」「完成防護」等可能造成安全保證的符號。

## 七、第一輪交付格式

第一輪產出一張 3×2 概念比較板，依序呈現六款方案。每格包含：

1. 大尺寸獨立圖標。
2. 橫式完整 Logo。
3. 約 32px 的小尺寸圖標預覽。
4. 概念名稱與一句簡短定位。

比較板使用暖象牙背景，不加手機 mockup、卡片陰影、照片或介面裝飾，讓判斷集中在 Logo 本身。第一輪是方向探索，不直接取代正式 Logo 資產。

選定一至兩款後，再進行第二輪：校正幾何、字距、單色版、深色底反白版、App icon 安全邊界與 SVG 重繪。

## 八、評選標準

六款方案依以下順序評估：

1. 32px 小尺寸是否仍清楚。
2. 是否能同時聯想到陽光／氣象與提醒節奏。
3. 是否成熟、溫暖，但不幼稚或醫療化。
4. 是否與一般天氣 App、保養品牌或計時器有足夠差異。
5. 中文主標與圖標搭配是否平衡。
6. 單色版是否仍保有辨識度。

## 九、第一輪完成條件

- 六款概念都符合共同規則且彼此不是只換線條的微小變體。
- 「防曬晴報員」與 `UVAlert` 文字完全正確。
- 每款都有獨立圖標、橫式組合與 32px 預覽。
- 不包含禁止方向中的圖形或色彩暗示。
- 使用者可直接從比較板挑選一至兩款進入第二輪。
