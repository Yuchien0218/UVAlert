# UVAlert 公開法律頁與隱私請求表單規格

## 目標

在 `https://uv-alert-web.vercel.app` 提供 Google OAuth 可使用的公開隱私權政策與服務條款網址，同時不公開開發者個人 Email。

## 公開網址與入口

- 隱私權政策：`/privacy`
- 服務條款：`/terms`
- 首頁與「更多」頁提供兩者連結；兩頁互相連結。
- 兩條路由不要求登入、不依賴提醒狀態，直接輸入網址也可開啟。
- 保留既有底部導覽；公開法律頁不新增底部導覽分頁。

## 頁面內容

### 隱私權政策

以清楚的繁體中文說明：

1. UVAlert 是協助記錄防曬與補擦提醒的工具，不是醫療服務。
2. 不登入時，提醒、裝備與偏好預設保留在裝置本機。
3. 使用者主動以 Google 登入並啟用同步時，系統使用 Google 提供的帳號識別資訊建立登入工作階段，並將使用者選擇同步的提醒、裝備與偏好儲存在 Supabase；不讀取 Gmail、Google Drive、聯絡人或其他 Google 服務資料。
4. 使用者主動啟用背景推播時，瀏覽器推播訂閱資料僅用於發送「該補擦防曬乳了」通知。
5. 使用者主動使用目前位置時，位置只用於當次地區判定，不保存精確座標或移動軌跡。
6. 資料處理目的、安全措施、使用者可在站內管理登入／雲端資料與清除本機資料的方式。
7. 聯絡／資料請求改由站內 `/feedback` 表單處理；不公開個人 Email。
8. 顯示生效日期與最後更新日期。

### 服務條款

以清楚的繁體中文說明：

1. 服務用途與使用者責任。
2. UV、天氣與提醒僅作為輔助資訊，不保證防曬效果或醫療安全；有健康疑慮應諮詢合格醫療專業人員。
3. 使用者應自行判斷戶外活動、防曬與通知設定。
4. 服務與資料來源可能調整；條款更新時更新頁面日期。
5. 隱私權政策與站內回饋表單連結。

## 隱私請求表單

- 擴充既有 `FeedbackType` 為 `privacy_request`。
- 表單選項新增「隱私／帳號資料請求」；訊息欄位請使用者說明需求，聯絡 Email 維持選填。
- 共用 contract、Edge Function validation 與資料庫 `feedback_type` check constraint 同步接受該值。
- 不新增登入要求、資料匯出或自動刪除行為；表單僅建立可人工處理的請求。

## 元件與資料流

- `PrivacyPolicyPage.vue`：只呈現固定政策內容與導覽連結，無狀態與 API 呼叫。
- `TermsPage.vue`：只呈現固定條款內容與導覽連結，無狀態與 API 呼叫。
- `FeedbackPage.vue`：呈現新增的 `privacy_request` 選項；既有 feedback controller 仍接收顯式 `FeedbackType`。
- Vue Router：提供 `/privacy`、`/terms` 的 lazy-loaded 公開路由與頁面標題。

## 失敗處理與驗證

- 靜態法律頁沒有遠端依賴；網路可用時可從網址直接開啟。
- 表單送出沿用既有 rate limit、欄位驗證與錯誤訊息；不在政策頁顯示私人聯絡信箱。
- 測試涵蓋公開路由、首頁／更多頁入口、法律頁必要的 Google 資料揭露文字，以及 `privacy_request` 在 contract、Edge validation、資料庫 constraint 與表單選項的一致性。
