# UVAlert 台灣繁體中文介面文案整理設計

## 文件資訊

- 日期：2026-08-17
- 狀態：已由產品方確認，待進入文案實作
- 適用範圍：目前使用中的 App／PWA 介面與公開衛教文章
- 語系：台灣繁體中文（zh-TW）
- 方向：清楚易懂版；保留「防曬氣象管家 × 防曬生活編輯部」的溫和語氣

## 1. 目標

讓台灣使用者一眼理解目前狀況、下一步要做的事，以及資料或提醒的限制。文案整理只改善語言、理解成本與一致性，不改變產品規則、提醒計算、資料模型、路由行為或衛教主張。

## 2. 範圍

### 會調整

1. `apps/web/src` 中實際呈現給使用者的頁面、元件、表單、按鈕、狀態、錯誤、空狀態與無障礙文字。
2. `docs/education/articles` 中公開文章的標題、摘要、小標題、段落、連結與閱讀提示。
3. 直接影響畫面顯示的前端 presentation 文案。
4. 因文字更新而需要同步的前端測試預期值。

### 不調整

1. `docs/archive/` 下的歷史文件、舊設計與舊文案。
2. API、資料庫、事件型別、路由 slug、文章 slug、SEO URL 與資料格式。
3. UV、SPF、抗水時間、醫療警示等健康主張的數字、證據與官方來源。
4. 未經另行確認的功能、頁面流程、提醒規則與資料保存策略。

## 3. 語氣原則

- 使用台灣常用繁體中文，避免中國大陸常見用語與直譯句型。
- 直接稱呼「你」，不使用過度正式或責備式的「您／使用者應該」。
- 先說明狀況，再說明原因，最後提供一個明確行動。
- 提醒頁短而直接；裝備頁像生活紀錄；衛教頁像編輯整理的生活專題。
- 錯誤訊息不責怪、不使用「糟糕」「Oops」等語氣，並提供恢復方法。
- 刪除、資料與隱私相關文字必須明確說出影響，不用模糊的「確定嗎？」。
- 不使用「保證不曬傷」「安全曝曬時間」「一定響鈴」等絕對承諾。

## 4. 統一詞彙

| 情境 | 統一用詞 | 補充 |
| --- | --- | --- |
| 核心功能 | 防曬提醒 | 不稱為安全計時器 |
| 倒數 | 補擦倒數 | 需要時可寫「下一次補擦倒數」 |
| 補擦動作 | 記錄補擦 | 動詞使用「記錄」 |
| 過去資料 | 補擦紀錄 | 名詞使用「紀錄」 |
| 防曬乳與配件 | 防曬裝備 | 防曬乳需明確時直接寫「防曬乳」 |
| 裝備導覽 | 裝備 | 不使用「產品」作為所有品類的總稱 |
| 更換防曬乳 | 換新的一瓶 | 不使用「再次購買」 |
| 部位集合 | 其他部位 | 不使用「其餘部位」 |
| 儲存動作 | 儲存 | 資料保存政策的「保存」可依語意保留 |
| 帳戶 | 登入／登出 | 不使用「登錄」 |
| 地理設定 | 地區 | 不任意改成「區域」 |
| 紫外線資料 | UV；首次可寫紫外線（UV） | 延續已確認的分類名稱「了解今天的 UV」 |
| 公開內容 | 衛教文章 | 不使用「知識庫」等技術詞 |

## 5. 修改順序

### 第一批：核心提醒與導覽

- 下排導覽統一為「提醒／裝備／更多」。
- 調整補擦倒數、目前提醒、到期、停止提醒、離線與通知狀態。
- 統一核心 CTA 與空狀態。

### 第二批：開始提醒與補擦流程

- 調整情境、塗抹時間、追蹤部位、產品標示、補擦確認、事件回報與紀錄更正。
- 讓每個操作按鈕直接描述下一步，不只寫「確認」「完成」。

### 第三批：裝備、更多與設定

- 調整裝備新增／編輯／分享、通知、本機資料、雲端同步、問題回報、安裝與隱私文字。

### 第四批：公開衛教文章

- 調整文章標題、摘要、小標題、段落與相關文章連結。
- 保留既有六大分類名稱、slug、官方來源、數字與限制。

## 6. CTA 與錯誤格式

### CTA

按鈕以動詞開頭，且可獨立理解：

- 開始防曬提醒
- 記錄補擦
- 儲存裝備
- 分享裝備
- 回報狀況
- 回到目前提醒
- 換新的一瓶

### 錯誤

使用「發生什麼事＋下一步」格式：

> 無法儲存，請檢查網路後再試一次。

避免只有「發生錯誤」「操作失敗」而沒有恢復方式。

## 7. 驗證方式

1. 使用 `rg` 檢查目前使用中的檔案是否仍混用已淘汰詞彙。
2. 更新受文案影響的 Vue／TypeScript 測試預期值。
3. 執行 `pnpm check`、`pnpm typecheck` 與 `pnpm build`。
4. 檢查手機窄寬度下的標題、按鈕、錯誤與衛教文章標題是否換行自然。
5. 確認封存文件未被修改，且文章 slug、來源與健康主張沒有變動。
