# UVAlert 台灣繁體中文文案 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 將目前使用中的 UVAlert App／PWA 介面與公開衛教文章整理成自然、清楚且一致的台灣繁體中文，不改變功能規則、資料模型或健康主張。

**Architecture:** 依照現有 Vue 元件與 presentation 檔案的責任邊界直接調整使用者可見字串，不新增全域 i18n 或大型文案抽象層。衛教文章維持現有 Markdown 與 slug，僅改可見標題、摘要、段落和連結文字；封存文件完全不碰。

**Tech Stack:** Vue 3、TypeScript、Vitest、Vite、Markdown、pnpm workspace。

## Global Constraints

- 只修改目前使用中的 apps/web/src 與 docs/education/articles；docs/archive 不得變更。
- 使用台灣繁體中文（zh-TW），採清楚易懂版語氣，保留「防曬氣象管家 × 防曬生活編輯部」的溫和調性。
- 核心詞彙固定為「防曬提醒、補擦倒數、記錄補擦、補擦紀錄、防曬裝備、換新的一瓶、其他部位、儲存、登入、地區」。
- 不修改提醒計算、事件型別、API、資料庫、路由 slug、文章 slug、SEO URL、官方來源、數字或健康主張。
- CTA 使用動詞開頭；錯誤訊息同時說明狀況與下一步；不使用安全保證或責備語氣。
- 不提交 .claude/settings.local.json 或其他與本任務無關的未追蹤檔案。
