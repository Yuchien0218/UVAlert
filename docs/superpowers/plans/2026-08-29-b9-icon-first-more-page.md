# B9 第一輪：「更多」頁 icon-first Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 讓「更多」頁的圖示從文字附件變成掃讀入口——圖示 20px → 32px、修掉六張雙色卡與兩張單色卡混用造成的視覺不一致、依逐項分類處置說明文字，並用前後量測證明版面確實變清爽而不是只變短。

**Architecture:** 尺寸級距與展開收合契約已在 B9 裁決 1、2 完成（`DESIGN.md` 第五、八節、`Icon.vue` 型別、5 個既有 disclosure 元件），本計畫只消費那些既有契約，不再改動它們。改動範圍限制在 `MorePage.vue` 一個檔案加上必要的測試與文件回寫。

**Tech Stack:** Vue 3 SFC `<script setup>`、TypeScript、CSS custom properties、Vitest、Vue Test Utils、Stylelint、Prettier、pnpm 11、Vite。

## 這一輪刻意不做 progressive disclosure

B9 規格有兩半——icon-first 與說明文字漸進揭露。**第一輪只做前者**，理由是把八張卡的說明文字逐項分類之後的實際結果：

| 處置 | 張數 |
| --- | ---: |
| 直接刪（純重述標題） | 1 |
| 縮短保留 | 2 |
| 可收進展開 | 0 |
| **必須常駐** | **4** |

七張卡裡有四張的說明是**決策條件或健康／安全邊界**，依 B9 §3 不可隱藏。**2026-08-29 合併之後，唯一那張「可收」的（本機資料管理）已經不存在了**——它被併進「本機資料與隱私」，新的說明文字整段都是必須常駐的隱私決策條件。也就是說這一輪連一段可收的文字都沒有，第一輪不做 progressive disclosure 的結論比原本更確定。

**disclosure 留給第二輪的設定頁**：`NotificationSettingsPage` 有 15 個 `<p>`、`ReportContextEventPage` 14 個、`EventCorrectionPage` 12 個，那裡才有足夠的可收文字支撐一套展開機制。

這個結論本身就是 B9 §5「**不進行全站批次刪文，也不只靠字數決定是否收合**」的直接應用。

> **✅ 前置依賴已完成（2026-08-29）**：`2026-08-29-settings-data-sync-merge.md` 的合併**已實作完成**——「跨裝置同步」併進「本機資料與隱私」，`/settings/sync` 移除。分類表已從八列改為七列，合併卡的說明文字已裁決。**B9 第一輪可以開工。**
>
> 連帶效果：Task 1 的「兩張單色卡怎麼處理」裁決點**只剩「特殊狀況」`state-warning` 一張**（`state-online` 隨卡片一起消失），而它被 publishable gate 擋住不渲染，可留到內容上線時再決定。

## Global Constraints

- 只動 `apps/web/src/pages/MorePage.vue` 與其測試；不碰核心提醒流程（`/`、`/setup`、`/reminder/reapply`）。
- 圖示尺寸只能用 `DESIGN.md` 第八節的四個檔位（16／20／24／32），不發明中間值。
- **不新增文案**。這一輪只做刪除與縮短，任何新的句子都要先裁決。
- **不可隱藏**：健康／安全邊界、不可逆操作後果、使用者採取動作前必須知道的條件、來源與審閱狀態（`DESIGN.md` 第五節）。
- 卡片仍是「整張可點進入」的連結，不引入第二種互動模式。
- 動畫遵守 `DESIGN.md` 第十二節五條規則；這一輪預期不需要任何新動畫。
- 每個 Task 結束時 `pnpm check` 必須全綠。
- 視覺改動一律用 Browser pane 實際跑起來看，不能只靠測試通過就宣稱完成。

### Task 1: 圖示放大到 32px 並統一色彩制

八張卡目前用 `:size="20"`，圖示只佔卡片面積 **1.61%**（304×82 的卡片配 20×20 圖示，390px 行動版實測）。

同時要處理一個放大後會變明顯的既有問題：**六張卡用雙色 `more-*` 圖示（墨咖＋琥珀金），兩張用單色 `state-*`**：

| 卡片 | 圖示 | 色彩制 |
| --- | --- | --- |
| 特殊狀況 | `state-warning` | 單色（繼承文字色） |
| 跨裝置同步 | `state-online` | 單色（繼承文字色） |
| 其餘六張 | `more-*` | 雙色（含琥珀金重點） |

20px 時琥珀金幾乎看不見所以差異不明顯；**32px 之後六張有重點色、兩張沒有，會直接讀成「這兩張比較不重要」**。

- [ ] 把八張卡的 `<Icon>` 從 `:size="20"` 改為 `:size="32"`
- [ ] 調整 `.entry` 的 grid／gap，讓圖示與文字區塊的對齊在單行與雙行說明下都成立
