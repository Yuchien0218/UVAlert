## C. 「防護機制」→「防曬原理」（已完成）

「機制」是規格書的詞。使用者要選的是物理性／化學性／混合型——那是「用什麼原理擋紫外線」。

**刻意避開「防曬類型」**：它右邊就是「劑型」，兩個「型」放在一起會被讀成同一組。衛教文章〈物理性、化學性、混合型防曬怎麼選？〉與食藥署頁面用的也都是「原理」這個角度。

同一段的「依包裝標示填寫，不從膚感推測。這三項只是紀錄，不影響補擦倒數。」整句刪掉：三個欄位都是下拉或自由文字，填錯沒有後果；而「不影響倒數」在同一個表單上方的 SPF／PA 那句已經講過。

## D. 清除確認框的排版跑掉（已完成）——**根因不是文案**

截圖上那句被切成三塊，逗號掉到行首：

```
裝備清單與已結束的提醒都會消失且
無法復原
，之後建立提醒需要重新填寫包裝標
示。確定嗎？
```

`.confirm-note` 是 `display: grid`，而 `#warning` slot 傳進來的是**裸文字＋一個 `<strong>`**。grid 會把每一段裸文字各自包成一個匿名 grid item，item 之間再吃一次 `gap: var(--space-3)`——於是「…都會消失且」／`<strong>無法復原</strong>`／「，之後建立提醒…」變成三個獨立的塊。

**同一個框的另一則也有病**：句中的 `<template v-if>` 會把模板換行帶成一個空白，畫面上是「全新狀態。 你這次還沒有匯出」，句號後多一格（與 #145 修過的「請先 設定地區 。」同一個坑）。拆成兩個 `<p>`。

處置：slot 內容一律包成區塊元素。守門是**掛載後檢查 DOM**（`.confirm-note` 底下不可以有非空白的裸文字節點）——掃原始碼字串抓不到，問題出在節點型別不是字串。ConfirmAction 的 `.confirm-note` 上補了註解說明這個 footgun。

文案順便精簡，砍掉結尾的「確定嗎？」——正下方那顆按鈕就叫「確定清除」，它本身就是在問。

## E. 「清除全部」那一列講三次同一件事（已完成）

原本是：紅色標題「清除全部本機資料」＋說明「清除本機資料，重置為初始狀態。」＋按鈕「清除全部」。說明那句只是把標題換句話說，而按鈕自己講完整的動作名稱之後，標題也沒有剩下的資訊。

**併成一顆按鈕**「清除全部本機資料」，紅字跟著搬到按鈕上——與 `GearDetailSheet` 的「刪除這件防曬裝備」同一套：危險動作用 `--color-due` 的**文字**，不用整顆紅按鈕。

實測確認 scoped CSS 選得到：`.clear-row--danger > .button` 的目標是 ConfirmAction **觸發態的根元素**（就是那顆 `<button>`，所以帶得到父層的 scope 屬性）；確認態的根是 `.confirm-note`，裡面的「確定清除／取消」不是根元素，選不到，仍是中性色。瀏覽器實測 `rgb(193, 68, 47)`、背景透明。

**仍待決**：同一張卡的另外兩列（「清除設定草稿」「清除裝備與提醒紀錄」）也是「標題＋一顆講同樣話的按鈕」。其中「清除裝備與提醒紀錄」的標題與按鈕文字**逐字相同**。這次只動使用者標註的那一列，沒有順手改。
