# UVAlert 全站文字整理盤點

**日期**：2026-08-17（Asia/Taipei）
**範圍**：現行 App／PWA、公開衛教內容、現行 Sitemap／User Flow 與設計文件
**基準**：台灣繁體中文；「防曬氣象管家 × 防曬生活編輯部」

## 本次統一規則

- 核心入口使用「提醒／裝備／更多」，根網址的頁面標題也使用「提醒」，不再把根網址稱作獨立「首頁」功能。
- 核心動作使用「開始防曬提醒」「記錄補擦」「查看最近紀錄」「更正這筆紀錄」「儲存」「換新的一瓶」。
- 防曬乳與其他配件統稱「防曬裝備」；只有會進入補擦計算的品類才稱為「防曬乳」。
- 地理與 UV 預報使用「地區」；「區域」只在文章討論一般地理範圍或設計區塊時保留。
- 使用「其他」而不是「其它」；使用「摩擦」而不是錯字「磨擦」。
- UV 分級沿用中央氣象署的五級中文標示，保留原本資料分類，不把分級轉成個人安全時間。
- 錯誤與限制文字先說明狀況，再提供下一步；刪除或停止操作的按鈕直接說出結果。

## 本次會處理的確認項目

1. 路由 title、頁面標題、導覽、按鈕、aria-label、placeholder、載入／錯誤／空狀態。
2. 提醒、開始設定、補擦、事件更正、地區、裝備、更多、回報、登入、同步與本機資料頁。
3. 公開衛教文章的標題、摘要、分類導讀、來源與 SEO/AEO/GEO 寫作規則。
4. 現行 Sitemap、User Flow、wireframe 與視覺方向文件中的頁面名稱與核心 CTA。

## 刻意不改動

- `docs/archive/` 的歷史文件與舊文案。
- 提醒計算、UV／SPF／抗水數字、事件型別、資料模型、API、路由 slug、文章 slug 與來源 URL。
- 健康、醫療、海洋環境與法務主張；只修正表達方式，不新增診斷、保證或零風險結論。
- 程式碼註解、測試描述與官方來源名稱中的必要專有名詞；它們不是使用者可見產品文案。

## 公開內容 SEO／AEO／GEO 文案基線

- 每篇文章只處理一個主要問題；H1、摘要與第一段先直接回答問題。
- 重要答案、條件、限制與來源必須出現在可讀文字中，不依賴互動展開或圖片文字。
- 連結文字描述目的地，例如「閱讀防曬配件怎麼挑」，不使用單獨的「了解更多」。
- 結構化資料、canonical、sitemap 與頁面可見文字必須一致；不為 FAQ rich result 或 AI 引用做不實保證。
- 健康內容保留作者／審閱者、查閱日期、官方來源與適用限制，並在正式發布前進行專業複核。
