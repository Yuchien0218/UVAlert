## 先說結論

會。**體感溫度不能拿來判斷 UV 強弱**。溫度描述空氣有多冷或多熱；UV 指數描述到達地表、可能造成皮膚與眼睛傷害的紫外線強度，兩者受不同因素影響。

## 為什麼涼涼的，UV 還是可能不低？

UV 會受到太陽高度、雲量、臭氧、海拔與地表反射等因素影響。風讓人覺得涼快，卻不會替皮膚擋住紫外線；春季、高山或海邊也可能出現「不覺得熱，但曝曬仍明顯」的情況。

比起用體感猜測，可以這樣做：

1. 出門前看所在地的 UV 指數與今日高峰。
2. UV 指數達 3 以上時，安排遮蔭、衣物、帽子、太陽眼鏡與裸露部位防曬。
3. 長時間戶外活動時，持續留意流汗、碰水與補擦需求。

## UVAlert 應該怎麼提醒？

UVAlert 可把氣溫和 UV 並列，但不應用「今天很涼」推論「不用防曬」。若預報資料暫時缺漏，也不應以溫度代替 UV 判斷。

## 文章限制

UV 指數是地區性的環境指標，不是個人的安全曝曬倒數。膚色、使用藥物、所在位置與實際遮蔽仍會影響風險。
