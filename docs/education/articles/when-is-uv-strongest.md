## 先說結論

一天中 UV 通常在太陽高度較高的中午前後比較強，中央氣象署的 UV 服務也會提供當日最大值。看到高峰時段，優先做的是調整活動、找遮蔭與穿戴防護，不是把它換算成「還能曬幾分鐘」。實際強度仍會受地點、季節、雲量與周遭反射影響。

## 為什麼中午前後比較強？

當太陽仰角較高時，UV 穿透大氣層的路徑相對較短，到達地面的紫外線通常較強。世界衛生組織（WHO）指出每日紫外線高峰通常落在正午前號數小時，中央氣象署亦提醒中午前後最容易出現極大值。

這不代表其他時間完全沒有 UV。早上、下午、陰天或冬天仍應依 UVI、活動地點和停留時間安排防護。

## 看見高峰時可以怎麼做？

1. 能調整就避開 UV 較強的時段，或縮短直射陽光下的停留。
2. 找有遮蔭的位置，先用衣物、帽子與太陽眼鏡遮住能遮的部位。
3. 防曬乳塗在衣物未覆蓋的皮膚，並依防曬乳標示與活動狀況補擦。
4. 若氣溫同時偏高，請務必補充水分、適度休息與降溫，防曬乳無法取代預防熱傷害的措施。

## 防曬晴報員顯示高峰時的限制

頁面上的「今天 UV 最強時間」應被理解為預報或觀測資料的時間資訊，而不是個人曬傷預測。地點改變、資料更新或天候變化，都可能使實際曝曬程度有所不同。因此資料畫面應同時標示地點、資料類型與更新時間。
