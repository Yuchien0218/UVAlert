## 先說結論

防曬配件不是只看顏色或價格，而是看「能遮住多少」和「有沒有清楚標示」。衣物可優先找 UPF 標示或織法緊密的款式；太陽眼鏡找 UV400 或「100% UV 防護」標示；帽子選能遮住臉、耳朵與後頸的寬邊款。陽傘、樹蔭和棚子能減少直射，但仍可能有散射與反射，所以要和衣物、眼鏡及裸露部位的防曬乳一起使用。

## 四種配件怎麼看？

### 1. 防曬衣物：看 UPF，也看穿著狀態

有 UPF（Ultraviolet Protection Factor）標示的衣物，較容易比較其紫外線防護等級；沒有標示時，可優先選擇織法緊密、能完整覆蓋皮膚的衣物。衣服被拉伸、磨損或弄濕後，防護能力可能下降，不能只看「長袖」三個字就當成完全防護。

### 2. 太陽眼鏡：深色不等於防 UV

FDA 建議找 UV400 或「100% UV 防護」標示。鏡片顏色深淺、品牌價格都不能單獨證明 UV 防護；包覆範圍較大的鏡框，通常也能減少側面光線進入。水面、沙地或雪地反射強時，更要確認眼鏡的 UV 標示。

### 3. 帽子：寬邊比只遮頭頂更完整

寬邊帽可以同時遮到臉、耳朵和後頸；棒球帽或有孔洞的草帽，常會留下耳朵、側臉與頸部空隙。若只能戴棒球帽，露出的部位仍要用衣物、遮蔭或防曬乳補足。

### 4. 陽傘與遮蔭：降低直射，不是 UV 絕緣

傘、樹蔭和棚子可以降低直射陽光，但周圍天空與地面仍可能帶來散射和反射。站在傘下時，仍要檢查臉、耳朵、手背、小腿與腳背等露出部位；也不要因為傘的顏色或價格就推論它能阻擋所有 UV。

## 出門前的配件檢查表

1. 衣物是否覆蓋肩膀、手臂、腿與頸部？布料是否過度拉伸、破損或濕透？
2. 眼鏡是否有 UV400 或 100% UV 防護標示？不要只看鏡片深不深。
3. 帽沿是否能遮到耳朵與後頸？如果不能，是否準備其他遮蔽或防曬乳？
4. 陽傘或遮蔽物是否仍有側面空隙？水、沙、雪或白色地面是否會反射？

配件是防曬乳倒數之外的日常紀錄：可以記下品牌、UPF／UV 標示、購買時間、價格、是否容易使用與實際遮蔽感受，但不要把使用者評價當成醫療防護保證。

## 文章限制

UPF、UV400 與「100% UV 防護」的標示制度可能依市場與產品類型不同；購買時應以產品標示與在地規範為準。本文不替特定品牌認證，也不保證單一配件能完全阻隔 UV；高 UV 或反射環境仍要減少曝曬並採用多層防護。
