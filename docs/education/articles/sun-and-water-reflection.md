## 先說結論

在水邊、沙地、雪地或明亮的混凝土環境，周遭表面可能把 UV 反射到皮膚與眼睛。走到樹蔭或遮陽傘下可以減少直射，但散射和反射仍可能存在。因此，遮蔭不是「完全不用防曬」的訊號，而是和衣物、帽子、太陽眼鏡及防曬乳一起使用的其中一層。

## 為什麼有遮蔭仍要留意？

UV 不只從頭頂直直照下來，也可能從天空散射或由周圍表面反射。水面、沙地、新雪與部分建材的反射程度會受環境影響，不能只用肉眼亮不亮或體感熱不熱來判斷。陰天、涼天也不代表 UV 一定很低，還是應查看所在地的 UV 預報。

這也表示「躲在傘下」和「完全沒有 UV」是兩件事。傘的角度、周圍空隙、活動時間與反射環境都會影響實際曝曬。

## 水邊或戶外活動的簡單搭配

1. **先減少直射**：選遮蔭處、調整活動時間，避免長時間待在 UV 較強的時段。
2. **遮住可遮的部位**：穿長袖或具 UPF 標示的衣物，搭配寬邊帽與能阻擋 UV 的太陽眼鏡。
3. **補上裸露處**：防曬乳只塗在衣物沒有覆蓋的皮膚，並依產品標示與活動狀況補擦。
4. **碰水後重新檢查**：游泳、流汗或毛巾擦乾後，不要只看原本的倒數。

## 不需要自行計算「反射加幾分」

沒有可靠的個人環境資料時，不要把某個反射百分比直接加到 UV 指數，也不要自行換算成可曝曬幾分鐘。看所在地預報、活動環境與自己的防護行動，會比複雜計算更實用。

## 文章限制

本文說明的是一般環境風險，不是個人 UV 劑量或曬傷診斷。若眼睛疼痛、畏光，或皮膚出現嚴重紅腫、水泡與全身不適，應尋求醫療協助。
