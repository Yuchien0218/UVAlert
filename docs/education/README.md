## 重要閱讀方式

這批文章依目前決定的六個分類整理，每篇只處理一個主要問題，並採用：

1. 先給直接答案。
2. 再說明適用情境與實際做法。
3. 清楚寫出限制，不把 SPF、UV 指數或倒數時間寫成個人安全保證。
4. 文末列出官方來源、查閱日期與本文限制。

文章是一般衛教，不是診斷、治療或個人化醫療建議。若讀者有持續或加重的不適、大片水泡、發燒、頭暈、噁心、眼睛疼痛、感染徵象或其他擔心的症狀，應尋求醫療專業協助。

## 文章資料格式

每篇文章都放在 `articles/`，使用固定欄位：

- `title`、`slug`、`category`：公開內容識別。
- `summary`、`primaryQuestion`：搜尋摘要與答案型內容基礎。
- `status`、`reviewStatus`：避免把草稿誤當已發布內容。
- `sources`：文章內完整列出的官方來源。
- `lastReviewed`：本次資料查閱日期，不代表醫療審閱已完成。
