# UVAlert 目前視覺方向

**日期**：2026-08-15  
**狀態**：已確認方向；尚未將整套新視覺重新實作到前端  
**用途**：提供 wireframe、UI／UX 與後續前端設計共同參考

## 一、品牌與角色

UVAlert 的品牌感受是「懂防曬知識、用生活化方式播報的氣象情報員」，而不是醫療警告工具或幼稚可愛的提醒 App。

視覺概念融合：

- **防曬氣象管家**：資料有來源、時間與風險層級，UV 色階要容易理解。
- **防曬生活編輯部**：衛教內容像經過編輯的生活專題，親切、整齊、有閱讀節奏。

## 二、不同區域的視覺任務

| 區域 | 視覺任務 | 設計重點 |
| --- | --- | --- |
| 提醒 | 讓使用者立刻知道現在要做什麼 | 倒數、下一步 CTA、部位狀態優先；避免裝飾搶走注意力 |
| 裝備 | 讓使用者快速查看與記錄防曬用品 | 清楚的清單、摘要與分享入口；不做購物商城感 |
| 更多 | 容納支援功能但保持整齊 | 同尺寸卡片、清楚分組、避免把次要功能做成警示牆 |
| 衛教首頁／分類頁 | 讓使用者像看生活專題一樣找到問題 | 編輯導讀、分類標題、短摘要與搜尋入口 |
| 衛教文章 | 讓健康資訊容易讀、容易查證 | 先給直接答案，再補條件、限制、來源與審閱資訊 |

## 三、色彩原則

- 基底採暖白、米色、柔和中性色，建立成熟且有陽光感的氛圍。
- 珊瑚橘／杏桃色可作品牌或編輯部的局部強調，不應填滿所有主要按鈕。
- UV 強度採局部色階，讓色彩代表資料意義，而不是裝飾。
- 狀態必須同時有色彩、圖示與文字；不能要求使用者只靠顏色判斷。
- 不使用綠色暗示「安全」或「防護有效」。
- 對比、焦點環、錯誤狀態與 reduced motion 仍以可及性為優先。

## 四、資訊層級與版面

- 每頁只保留一個最主要任務與一個主要 CTA。
- 提醒頁採「先結論、後細節」：目前狀態 → 倒數／下一步 → 部位摘要 → 次要資訊。
- 衛教頁可有較強的編輯層次，但重要答案與來源不能藏在裝飾或互動後面。
- 使用留白、分隔線與文字層級建立秩序，避免每一塊內容都變成同重量的卡片。
- Sitemap／User Flow 文件本身另採純文字樹狀結構；不要把文件圖像化風格誤套到產品介面。

## 五、目前程式碼基線

目前前端的實際視覺來源是：

- `packages/ui/src/styles.css`：品牌基礎色、提醒狀態色、UV 色階、字體、間距、圓角、陰影與動畫。
- `apps/web/src/assets/app.css`：頁面堆疊、標題、資料數字、卡片、狀態卡、UV badge、按鈕與連結樣式。

目前 token 大致已分成「基礎值」與「語意別名」兩層；未來若要進一步擴充，才評估加入元件層 token，不在本次整理中直接改 CSS。
