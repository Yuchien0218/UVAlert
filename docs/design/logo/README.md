## 字體

中文字標使用**源泉圓體（GenSenRounded）TW 月版**，Medium 字重。
英文副標 `UVAlert` 使用 Inter Medium／500（目前橫式標誌未含英文副標）。

- 授權：SIL Open Font License 1.1，可自由商用
- 取得：[ButTaiwan/gensen-font](https://github.com/ButTaiwan/gensen-font)
- **一定要用 TW（月版）**，不要用 JP／PJP（日文）或 TC（丹版）。TW 版採用台灣近年多數字型習慣的通俗寫法，字形符合台灣標準；日文版的漢字字形與台灣標準不同（「曬」在日文是擴充字，「晴」的青部寫法也不同）。

### 為什麼是圓體，不是襯線體

2026-08-22 從 `Noto Serif TC` 改過來。原因是圖標的造型語言定義為「實心圓點＋膠囊狀線條，端點與轉角一律 `round`，**不使用尖角**」（`DESIGN.md` 第八節），而尖角正是明體的特徵——圖標與字標互相打架。

圓體是黑體的圓角版本：結構不變、只磨圓筆畫端點，正好呼應膠囊語言。刻意**不選** jf open 粉圓，因為那會越過 `DESIGN.md` 第一節「允許溫度，不允許可愛化」那條線。

這個選擇**只適用於字標**。內文與標題仍依 `DESIGN.md` 第三節使用襯線體——Logo 有自己的字體是正常且常見的做法。

## 修改時的規則

1. **改 `.ai`，不要手改 SVG 的 `path` 資料**（與 `docs/design/icon-system/README.md` 同規則）。
2. 匯出 SVG 前，在 Illustrator 把文字**建立外框**（`Ctrl+Shift+O`）。留著活的 `<text>` 會讓沒裝該字體的機器渲染成別的字。
3. 匯出後整理：移除 Illustrator 的 `id`／`data-name`／`isolation` 雜訊，把 `cls-*` 換成直接的 `fill`，補上 `role="img"`／`<title>`／`<desc>`，並用 `data-part="mark"`／`data-part="wordmark"` 分組。
4. 顏色只能是墨咖 `#33291F` 與琥珀金 `#C1832E`（`DESIGN.md` 第八節的圖示／Logo 專用配色）。**不要**代入介面配色的深杏桃 `#9F5E42`——那兩套範圍不同。
