# UVAlert 進行中提醒主頁：六款低擬真 Wireframe 設計規格

**日期**：2026-08-17  
**用途**：產出六張可分開檢視的手機端灰階低擬真 Wireframe  
**狀態**：版型方向已確認；等待產圖

## 一、設計目標

以「已有進行中提醒」為共同狀態，探索六種明顯不同的主頁資訊架構。六款使用相同產品需求，只改變資訊優先順序、分組方式與閱讀動線，方便後續比較哪一種最適合進入正式 wireframe 與 UI／UX 設計。

本次只做低擬真版型草稿，不決定正式色彩、字體、圖示、插畫、品牌 Logo、動畫或元件細節。

## 二、輸出形式

- 產出六張獨立圖片，分別標示 A、B、C、D、E、F。
- 每張只呈現一個直式手機畫面，不把六支手機並列在同一張圖。
- 不使用手機外框、手持情境或裝置 mockup。
- 使用白、淺灰、深灰和黑色線框；不使用品牌色與 UV 彩色色階。
- 使用簡單繁體中文標籤，不放照片、Logo、插畫或精細圖示。
- 畫面應像 UX 設計階段的灰階線框稿，不像已完成的高擬真 App。

## 三、六款共同資訊

每款都必須能辨識以下內容：

1. 今日 UV 指數、資料時間或最強時段摘要。
2. 主要補擦倒數。
3. 清楚的目前狀態或下一步提示。
4. 單一主要 CTA「記錄已補擦」。
5. 正在追蹤的部位摘要；不顯示尚未追蹤或已停止的部位。
6. 最近事件入口或最近一筆事件摘要。
7. 小型通知、背景提醒或離線狀態提示位置。
8. 固定下排導覽：「提醒」「裝備」「更多」，目前頁為「提醒」。

次要功能不得搶過倒數與「記錄已補擦」。

## 四、六款版型

### A．大倒數中心型

- 頂部：頁面名稱、所在地或資料時間、UV 小摘要。
- 中央：最大面積的圓形或方形倒數區。
- 倒數下方：下一步提示與主要 CTA。
- 下半部：追蹤部位摘要、最近事件、小型狀態提示。
- 特徵：視線第一時間落在剩餘時間。

### B．今日播報型

- 頂部：較高的「今日 UV 播報」區，包含目前 UV、最強時段與一句生活化摘要。
- 中段：橫向倒數區與主要 CTA。
- 下段：部位摘要與最近事件。
- 特徵：像先看今日氣象，再處理防曬任務。

### C．部位狀態型

- 頂部：精簡 UV 與倒數。
- 中央：正在追蹤部位的狀態列表或分組區，顯示「全部」或不同到期狀態。
- 中段固定主要 CTA。
- 下方：最近事件和背景提醒狀態。
- 特徵：適合需要快速理解哪些部位即將補擦的使用者。

### D．行動優先型

- 頂部：一句清楚結論，例如「距離補擦還有 42 分鐘」。
- 緊接著：最大、最醒目的「記錄已補擦」按鈕。
- 中段：較小的倒數與追蹤部位摘要。
- 下段：UV、最近事件與通知狀態。
- 特徵：先讓使用者完成任務，再補充資料。

### E．直向時間軸型

- 頂部：今日 UV 小摘要。
- 主體：直向時間軸，串連「已塗防曬」「目前倒數」「預計補擦」「最近事件」。
- 主要 CTA 放在目前節點附近。
- 部位摘要放在預計補擦節點下方。
- 特徵：用時間順序解釋現在位於哪個階段。

### F．儀表摘要型

- 頂部：標題與狀態提示。
- 首屏：倒數為最大區塊，UV 與追蹤部位為兩個較小摘要區。
- 中段：主要 CTA 橫跨整列。
- 下方：最近事件與下一次提醒資訊。
- 特徵：同時看到多項狀態，資訊密度最高，但仍保持單一主要操作。

## 五、文案與畫面限制

- 倒數範例統一使用「00:42:18」，避免六款因時間不同造成誤判。
- UV 範例統一使用「UV 6｜高量級」及「今日 12:00 最強」。
- 部位範例統一使用「臉部、頸部與耳朵、手臂」，其它部位可用「其它部位」摘要。
- 最近事件範例使用「10:20 已補擦全部部位」。
- 小型狀態範例使用「背景提醒已開啟」。
- 不加入尚未確認的新功能、成就、連續天數、健康分數或過往統計。
- 不把衛教文章、裝備分享或捐款入口放到提醒主頁。
- 不顯示尚未追蹤或已停止的部位。

## 六、檢視標準

每張圖應符合：

- 不看說明也能先找到倒數與主要 CTA。
- 六款在資訊架構上有明顯差異，不只是卡片交換位置。
- 共同資訊完整，能公平比較。
- 灰階層級足以表現閱讀順序，但不進入 UI 視覺細節。
- 小尺寸預覽時仍能辨識主要區塊。

## 七、範圍外

- 尚未開始提醒的主頁。
- 到期、逾時、離線失敗或權限拒絕等其它狀態。
- 設定流程、補擦表單與事件更正畫面。
- 平板、桌面與響應式版型。
- 正式 UI、視覺設計系統與前端實作。
