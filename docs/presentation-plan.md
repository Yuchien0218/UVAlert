1. **痛點一：上班上課太忙，容易忘記補擦**

   * *解法*：**打開直接用，預設最安全的 120 分鐘**。完全不用打字建檔，點選部位就能立刻開始倒數。
3. **痛點三：洗完手、流完汗，只補了手，臉卻漏掉**
   * *解法*：**臉、手分開獨立計時**。洗手只會扣減手部的保護時間，並且會主動提示你接著補擦手部。

### P.7 【衛教專欄】SEO、AEO、GEO 搜尋與 AI 引用優化（40 秒）

#### 投影片畫面上放什麼

* 三大優化機制對比卡片：
  * **SEO（傳統搜尋）**：預先產生靜態 HTML 網頁、自動產出網站地圖（Sitemap）。
  * **AEO（搜尋答案摘要）**：先講結論的結構、嵌入 Article 結構化資料。
  * **GEO（AI 搜尋引用）**：清楚聚焦單一問題、附上官方可靠出處與審閱日期。

#### 投影片條列重點
* **為什麼防曬工具要做搜尋優化？**
  * 使用者遇到曬傷或不知道怎麼選防曬時，第一動作通常是上 Google 或問 ChatGPT。
* **三大搜尋面向的實作策略**：
  1. **SEO（搜尋引擎優化）**：打包時自動把 Markdown 文章轉成**純靜態 HTML 網頁**，搜尋爬蟲不用執行 JavaScript 就能直接秒讀。
  2. **AEO（問答型搜尋優化）**：文章結構嚴格遵守「**開頭 1～3 句先直接給出結論**，後面再補充條件與細節」，讓搜尋引擎能直接抓取為精選答案卡。
  3. **GEO（生成式 AI 引用優化）**：每篇文章**只聚焦單一核心問題**，重要數據清楚寫在文字中，並附上**官方醫學來源與專業審閱日期**，確保 AI 引用時資訊準確、不產生幻覺。

#### 演講講稿（40 秒）

### Q1：這個產品算不算是醫療器材或醫療軟體？有沒有法律風險？
* **白話回答**：
  > 「完全不算。我們在規劃之初就做了嚴格的合規界線分析：UVAlert 屬於『生活習慣與日常自我照護的輔助工具』，而非醫療軟體。我們在服務條款中明確寫道『不提供疾病診斷、不提供個人化醫療處方、補擦提醒不代表安全曝曬效果保證』。當使用者遇到嚴重曬傷或特殊皮膚病變時，系統一律引導停用並就醫，完全避開醫療行為的法律風險。」

### Q2：你們的後端在沒有網路或沒有登入時，資料會不會不見？
* **白話回答**：
  > 「完全不會。因為我們的架構是『本機優先（Local-First）』，所有提醒事件、自訂裝備與倒數狀態，都是第一時間寫入使用者手機瀏覽器的 IndexedDB 資料庫中。後端伺服器純粹是『選配的雲端備份與多裝置同步』，就算使用者這輩子都不登入、或者在深山沒有網路，核心倒數功能依然 100% 運作無虞。」

### Q3：為什麼說定位完全不上傳？那是怎麼知道使用者在哪一區的？
* **白話回答**：
  > 「一般軟體是把手機經緯度送到後端伺服器，由伺服器查地圖再回傳；但這樣伺服器就會留存用戶的 GPS 軌跡。我們的做法是：事先把內政部的台灣鄉鎮邊界圖形資料做壓縮，放在網頁前端。當使用者點擊定位時，手機瀏覽器只在自己的記憶體中比對經緯度落在台灣哪一個鄉鎮的多邊形裡面，算完立刻把經緯度清空，所以伺服器完全碰不到用戶的精準位置。」

### Q4：衛教專欄提到的 SEO、AEO、GEO，主要差別是什麼？
* **白話回答**：
  > 「SEO 是傳統搜尋，重點在於讓 Google 爬蟲不用跑 JavaScript 就能抓到我們的靜態 HTML 網頁；AEO 是問答優化，重點在於文章開頭先給一段直接清楚的答案，讓搜尋引擎能直接擷取成搜尋結果頁的答案卡；而 GEO 是讓像 ChatGPT 或 Google AI 摘要在幫人回答時，能精準引用我們的內容，關鍵在於資訊聚焦、附上官方可靠出處與審閱日期，避免 AI 產生幻覺。」
