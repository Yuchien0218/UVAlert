## 建議閱讀順序

1. 先讀 [`../education/README.md`](../education/README.md)，確認文章分類、發布狀態與內容界線。
2. 需要查主張時，讀六大主題官方來源筆記，再回到 [`../education/sources.md`](../education/sources.md) 的集中來源索引。
3. 需要擴充題目時，再讀擴充主題與搜尋趨勢筆記。
4. 需要公開搜尋工程時，讀 SEO／AEO／GEO 筆記與 [`../education/public-seo-implementation.md`](../education/public-seo-implementation.md)。

## 證據使用規則

- 優先採用臺灣中央氣象署、衛生福利部相關機關與其他文件列出的第一方／專業機構來源。
- 研究筆記中的「搜尋趨勢」是質性選題線索，不代表精確搜尋量、排名或使用者比例。
- 「reef-safe」「ocean-friendly」等標語沒有全球一致定義；不可寫成零風險或官方統一認證。
- 健康主張、數字、產品標示與台灣法規在發布前仍需重新確認。
