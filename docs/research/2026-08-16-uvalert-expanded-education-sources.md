# UVAlert 衛教擴充主題：官方第一手資料研究筆記

## 研究資訊

- **查閱日期：**2026-08-16（Asia/Taipei）
- **用途：**提供 UVAlert 後續擴充衛教文章、SEO／AEO 內容與介面文案使用。
- **研究範圍：**六組擴充主題：UV 預報與每日最大值、低 UV／夜間與資料限制；防曬產品保存／效期／臉部／眼周／嘴唇；重新外出、補擦前清潔與短暫外出；流汗碰水後的乾燥、補水與熱傷害區分；曬後保濕與恢復期間防護；受傷／破損皮膚與產品資訊保留。
- **來源優先序：**臺灣中央氣象署、衛生福利部國民健康署、衛生福利部食品藥物管理署優先；再以 WHO、FDA、CDC、AAD、NHS、Cancer Council 等第一方或專業機構資料交叉確認。
- **交付界線：**本文件是文章撰寫用的研究筆記，不是診斷、處方或個人化醫療建議；只新增本研究筆記，不修改程式碼或既有衛教文章。
- **日期讀法：**「頁面日期」是來源頁面明示的發布、更新或最後修改日；未明示者記為「未標示」，不自行推測。所有來源的查閱日均為 2026-08-16。

## 結論先行

1. **UV 預報的「今日最大值」不是全天每個時刻的即時 UV。**中央氣象署的預報以每日最大值呈現；WHO 說明最大值通常出現在太陽正午前後的約四小時區間。介面應同時顯示地點、資料類型、有效／更新時間。
2. **夜間或沒有日光時，太陽 UV 指數通常接近零，但「低 UV」不等於任何情境都不需要注意。**UVI 是太陽 UV 的環境指標，不涵蓋日曬燈、消毒燈或其他人工 UV；低 UV 也不應被轉成個人「可以曝曬幾分鐘」。
3. **防曬產品要看效期、保存環境與外觀狀態。**臺灣食藥署建議依包裝的製造日期／有效期間／保存期限與保存方法判斷；車內、窗邊、浴室等高溫潮濕或日曬環境可能加速變質。
4. **臉部、眼周與嘴唇不能用「全身同一種塗法」簡化。**防曬產品應避開眼睛與口腔；嘴唇使用標示適用唇部且有 SPF 的護唇產品，噴霧不可直接噴臉。
5. **短暫外出仍是曝曬事件，重點是 UVI、時間、遮蔽、反射與個人狀況，而不是「只出去一下」四個字。**目前官方資料沒有可套用所有人的「短於幾分鐘就不用防護」規則。
6. **補擦前不需要每兩小時完整洗臉。**官方資料支持依產品標示補擦、流汗／游泳／毛巾擦乾後更早補擦；若皮膚明顯髒、油、濕或有汗，可先溫和清潔／輕拍乾，再均勻補擦。這一點是保守的 UX 整理，不是單一機構的固定演算法。
7. **流汗或碰水後要把「補擦防曬」與「補水、休息、降溫」分開。**防曬產品不會預防熱傷害；若出現頭暈、噁心、意識改變、體溫過高等疑似熱傷害，應先離開高溫環境並尋求醫療協助。
8. **曬後保濕是舒緩與保護，不是讓皮膚立即恢復。**曬傷可能在 24–36 小時內變嚴重，恢復時間因程度而異；仍紅、痛、脫皮或起水泡時，應避免日光直射，不要把防曬倒數當作「已經痊癒」判定。
9. **破皮、起水泡或有明顯發炎時，不要把一般防曬乳當作傷口處理產品。**美國 FDA 的防曬標示要求寫明不要用於受損或破皮皮膚；臺灣食藥署則建議停用可疑產品、就醫並保留完整包裝、成分、批號與效期。

### 文章可以怎麼寫

1. **「UV 預報的今日最大值，應該怎麼看？」**  
   先解釋「預報／觀測」與「每日最大值」差異，再讓讀者知道要看地點與更新時間。
2. **「晚上 UV 很低，防曬倒數要不要繼續？」**  
   說明太陽 UV 與人工 UV 不同；低或零太陽 UVI 可停止一般防曬倒數，畫面改顯示明日預測或資料狀態，但不要把低 UV 寫成全天候無風險。
3. **「為什麼 App 的 UV 數字和戶外感覺不一樣？」**  
   說明雲量、反射、海拔、地點差異、預報與觀測時點，以及資料暫缺；不把落差解釋成一定是產品故障。

### UVAlert 的產品與文案邊界

- 首頁至少呈現：地點、資料類型（今日預報／氣象站觀測）、資料時間、最大 UVI、CWA 分級與資料限制。
- 如果顯示「今天 UV 最強時間」，必須確認資料真的提供時段；只有每日最大值時，應寫「今日最大值」或「通常出現在中午前後」，不要假造精確時刻。
- 晚上可切換成「今日 UV 已低／目前沒有太陽 UV 防曬倒數」與「明日 UV 預測」；這是產品行為，不是官方要求。文案要保留「僅針對太陽 UV」的限制。
- 預報過期、地點未取得或 API 回傳 -999 時，不要沿用昨天數字假裝是今天；顯示「暫無 UV 資料」與通用遮蔽／衣物／帽子建議。
- 不使用 CWA 文件中「高量級 30 分鐘內、過量級 20 分鐘內」等內容作為個人倒數；若文章提到，需強調那是公共衛教分級，不是個人保證。

### 文章可以怎麼寫

1. **「防曬乳放車內、窗邊，還能用嗎？」**  
   以保存環境、外觀變化、效期與產品標示為主，不讓讀者只看「有沒有變色」。
2. **「防曬乳過期、忘記何時買，該怎麼判斷？」**  
   先看臺灣產品包裝的有效期間／保存期限；未知年齡或已變質就不要使用。美國三年規則只能放在「國外資料提醒」，不能變成臺灣硬規則。
3. **「臉、眼周與嘴唇的防曬，可以用同一瓶嗎？」**  
   以「依產品標示、避開眼睛與口腔、嘴唇用 SPF 護唇產品、噴霧不直噴臉」回答，避免推薦特定品牌。

### UVAlert 的產品與文案邊界

- 裝備／防曬乳紀錄可增加欄位：購買日期、效期、保存方式、產品形式、使用部位與備註；不要讓 App 自己推算臺灣法律上的產品效期。
- 可提供「快檢查」提示：效期、是否長時間放車內／烈日、是否有變色／異味／油水分離／結塊。
- 「眼周」在部位紀錄上可以保留為臉部的一部分，但文章要提醒只能依產品標示、避免直接進眼睛；不把「眼周」改成「眼睛」。
- 嘴唇要有獨立文案：「使用標示適用唇部的 SPF 護唇產品」，不要叫使用者把一般防曬乳吃進嘴裡。
- 防曬保存文章不要保證產品一定安全；若不適，停止使用、清水清潔（依產品／TFDA 指引）並諮詢醫療專業。

## 3. 重新外出、補擦前清潔與短暫外出

### 可採用的主張

| 衛教主張 | 官方來源與直接 URL | 頁面日期；查閱日 | 適用限制 |
|---|---|---|---|

### 建議的使用流程（文章可直接轉成步驟）

1. **先看這次要去哪裡與 UVI。**短暫走到便利商店、通勤、遛狗或取物，不等於完全沒有 UV；若 UVI 較高，優先使用遮蔭、帽子、衣物與適合的防曬。
2. **檢查上一次塗抹與事件。**若已接近一般兩小時基線，或中間流汗、碰水、游泳、擦過毛巾，就把它當成需要重新處理的事件。
3. **補擦前只做必要清潔。**若皮膚乾淨且產品仍均勻，可依產品標示直接補擦；若有汗水、油脂、髒污或水分，先溫和清潔／沖掉明顯髒污，輕拍乾，不用力搓到發紅。
4. **回到安全處再補擦。**不要在開車、騎車、仍在水中或危險交通環境中操作；先停在安全、遮蔽且可以均勻塗抹的地方。
5. **產品標示優先。**不同劑型、抗水標示、臉部／嘴唇適用範圍不同；App 只能提醒事件，不能替換仿單。

### UX 轉譯建議

- 把「短暫外出」設成文章情境，不設成免防曬的例外開關。
- 重新外出時可顯示：「這次還要出門嗎？先確認上次塗抹、是否流汗／碰水，再決定要不要補擦。」不要寫成「只要在室內就永遠不用重算」。
- 補擦前可以提供兩個操作：「直接補擦」與「先清潔再補擦」；後者只在使用者有汗、水、髒污或油脂時建議。
- 不把「清潔」做成每次補擦必經的長流程，避免讓核心倒數功能變得麻煩。

### 文章可以怎麼寫

1. **「流汗或游泳後，先擦乾還是先補擦？」**  
   回答「先到安全處，輕拍去除多餘水分，不要用力搓；再依產品標示均勻補擦」，並提醒抗水不是防水。
2. **「補水和補擦防曬，是同一件事嗎？」**  
   明確拆成兩條：補擦是恢復皮膚防護層，補水／休息／降溫是預防熱傷害。
3. **「淋雨後沒有流很多汗，也要補擦嗎？」**

### UX 轉譯建議

- 事件按鈕可使用白話：「流汗了」、「碰到水／游泳」、「用毛巾擦乾」；不要讓使用者自己理解 40／80 分鐘法規。

- 熱傷害警訊應是獨立的高優先級內容，不要塞在一般倒數通知或讓使用者以「已補擦」關閉。

### 重要的來源差異

- AAD 提到可用凡士林保護水泡；NHS 對曬傷皮膚則提醒不要使用 petroleum jelly。兩者情境與指引文字不同，正式文章不應把其中一種寫成所有曬傷都適用的固定處方。
- CDC、NHS 對恢復天數的描述也不同；文章應使用「通常需要數天，程度不同會不同」或「直到紅、痛、脫皮／水泡等症狀改善」，不要承諾 3 天或 7 天一定痊癒。
- 不在一般衛教文章中自行推薦口服止痛藥、外用類固醇或抗生素；若要保留官方提及的藥物，需由醫療專業人員審閱年齡、疾病、懷孕與用藥限制。

### 文章可以怎麼寫

1. **「曬後保濕要怎麼做，才不會越擦越刺激？」**  
   以冷卻、輕拍乾、選無香精或適合自己的保濕品為主；避開香精、酒精、磨砂與用力按摩等可能刺激內容，並標註個人差異。
2. **「皮膚還在脫皮，可以繼續防曬嗎？」**  
   回答「仍要防護，但先用遮蔭與衣物；破皮處不要自行套用一般防曬乳，依產品警語或專業意見處理」。
3. **「曬傷大概要多久才會好？」**  
   說明曬傷可能延後變嚴重，恢復天數有差異；以症狀是否持續／惡化與紅旗警訊作為求助依據，不用固定天數關閉提醒。

### UVAlert 的產品與文案邊界

- 「回家後與皮膚照顧」可提供舒緩與觀察流程，但不要讓它取代醫療分流。
- 曬傷期間可將防曬倒數顯示為「目前以遮蔭／衣物保護為主」，避免要求使用者在破皮處硬擦。
- 文章應把「已完成保濕」與「已恢復」分開；保濕紀錄不能自動解除醫療提醒。

### 建議的「產品資訊保留」清單

當使用者需要就醫或回報防曬／化粧品問題時，可提醒保留：

- 產品名稱、品牌、劑型與防曬標示。
- 完整包裝或標籤照片。
- 全成分、批號、製造／輸入業者。
- 製造日期、有效期間／保存期限、購買日期與購買通路。
- 使用部位、使用時間、使用量與是否同時使用其他產品。
- 紅、腫、癢、痛、起疹、水泡等反應的開始時間與變化。
- 在不暴露個資的前提下，依醫療專業人員需求記錄照片；不要為了「測試」再次使用可疑產品。

### 文章可以怎麼寫

1. **「破皮、傷口或水泡上可以擦防曬嗎？」**  
   先回答：不要自行把一般防曬乳塗在破皮／受損處；依產品警語、先用衣物／遮蔭保護並詢問專業人員。
2. **「擦防曬後紅、癢、刺痛，怎麼留下有用的紀錄？」**  
   提供停用、清潔、記錄症狀、保留包裝與就醫流程；不替使用者診斷。
3. **「去看醫師時，防曬乳的哪些資訊要帶？」**  
   以產品完整包裝、成分、批號、效期、購買與使用紀錄為主，讓讀者容易實作。

### UVAlert 的產品與文案邊界

- 產品紀錄可以支援「上傳／拍攝標籤」與「備註」，但第一版不應要求使用者提供醫療照片或將照片公開分享。
- 分享產品心得與「不適回報」應分開；一般心得不是醫療安全背書。
- 若有破皮、起水泡、快速腫脹、眼睛不適或症狀持續，停止使用並引導醫療協助；不使用「換一瓶就好」作為唯一建議。
- 保留產品資訊的目的是讓醫師／主管機關更容易判斷與追蹤，不代表 App 可以確認產品造成症狀。

## 跨主題的安全文案規則

### 可以採用

- 「UV 預報是環境資訊，先看地點、資料時間與預報／觀測類型。」
- 「UVI 3 以上，依情境採取遮蔭、衣物、帽子、眼鏡與防曬等組合防護。」
- 「短暫外出也可能接觸 UV；不要用固定分鐘數判斷所有人的風險。」
- 「一般戶外活動至少每兩小時補擦；流汗、游泳或毛巾擦乾後依產品標示更早補擦。」
- 「先到安全處輕拍乾，再依產品標示補擦；補水、休息、降溫和補擦防曬是不同事情。」
- 「皮膚仍紅、痛、脫皮或有水泡時，先避開日光；破皮處不要自行套用一般防曬乳。」
- 「產品不適時先停用、記錄症狀、保留完整包裝，必要時就醫。」

### 不應直接採用

- 「現在 UV 是 0，所以任何紫外線都沒有。」（UVI 主要描述太陽 UV，不涵蓋人工 UV。）
- 「今日最大 UV 是 8，所以你一定會在 20 分鐘曬傷。」（把公共分級變成個人倒數。）
- 「防曬乳放車內只要沒有變色就一定能用。」（保存不當可能影響穩定性，外觀正常也不能推翻效期。）
- 「美國規則是三年，所以臺灣所有防曬乳都能用三年。」（法規與產品標示不同。）
- 「每次補擦前都要用洗面乳洗臉。」（可能增加刺激，也不是官方通用規則。）
- 「補水就等於完成防曬。」（熱傷害與 UV 防護是兩種不同風險。）
- 「曬紅後繼續擦防曬就會加速恢復。」（防曬不是曬傷治療；破皮處還可能不適用。）
- 「App 判定你過敏、中暑或曬傷。」（需要醫療評估。）

## 研究限制與上線前複核

- 各國的 SPF 門檻、產品分類、效期標示與 water-resistant 法規不同；UVAlert 第一版應以臺灣產品標示與臺灣官方文案為主。
- 「每兩小時」是一般戶外補擦基線，不是 SPF 的時間倍數，也不是個人安全曝曬上限。
- CWA 預報與每日最大觀測資料會更新；工程上仍需確認 API 的地點對應、時間戳、空值／-999、更新失敗與預報過期狀態。
- 夜間低／零 UV 的文案只適用於太陽 UV；不能延伸成「任何人工 UV 都安全」。
- 曬傷、熱傷害、過敏與感染的分流需由具備相關專業能力的人員審閱；App 不應自行診斷。
- AAD、NHS 對部分曬傷外用照護細節存在差異；正式文章應選擇不衝突的共通安全內容，或清楚標示來源與個人差異。
- 上線前逐篇檢查：來源 URL、頁面日期、查閱日期、臺灣法規、產品標示、文章撤回流程、SEO 結構化資料與手機閱讀。
