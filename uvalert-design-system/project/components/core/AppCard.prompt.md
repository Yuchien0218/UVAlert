The neutral container — forecast cards, forms, panels that sit on the ivory floor.

```jsx
<AppCard><h2 className="title-md">五日預報</h2>…</AppCard>
```

Border is a hairline (`--color-hairline`) and reads as one step of elevation, not an ink line. Never add a shadow. For warm cream cards (gear, more, education) use `GearListItem` / `MoreEntryCard` / `EducationCategoryCard` instead — and avoid making every block on a page a card of equal weight.
