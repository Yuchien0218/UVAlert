The zone summary list under the countdown panel.

```jsx
<ZoneStatusRow zone="臉部" tone="due" stateLabel="該補擦了" remaining="0 分" />
```

- Transparent rows with hairline-soft dividers — not 16 individual cards.
- The state icon is a remaining-capacity meter (3 capsules → 1 → empty → empty + slash), so the state survives greyscale and colour blindness.
- Never draw body-part illustrations; the zone is a text label.
